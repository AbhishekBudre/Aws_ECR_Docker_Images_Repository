# Three-Tier Application Deployment Using AWS ECR

## 1. Project Overview

Deploy a Three-Tier Application on AWS EC2 using Docker containers and Amazon Elastic Container Registry (ECR).

The application consists of three Docker containers:

- **Frontend:** User interface
- **Backend:** Application API
- **Database:** PostgreSQL database

Docker images are automatically built and pushed to AWS ECR using GitHub Actions CI Pipeline.

## 4. Authenticate AWS ECR

Install and configure AWS CLI on your EC2 instance.

Configure AWS credentials or attach an IAM role with the `AmazonEC2ContainerRegistryReadOnly` policy.

Login to AWS ECR:

```bash
aws ecr get-login-password --region ap-south-1 | docker login \
  --username AWS \
  --password-stdin 667173675235.dkr.ecr.ap-south-1.amazonaws.com
```

## 9. Run PostgreSQL Container

```bash
docker run -d \
  --name my_postgres \
  --network mynetwork \
  --restart unless-stopped \
  -e POSTGRES_USER=admin \
  -e POSTGRES_PASSWORD=12345 \
  -e POSTGRES_DB=mydatabase \
  -v pgdata:/var/lib/postgresql/data \
  667173675235.dkr.ecr.ap-south-1.amazonaws.com/my-devops-webapp-database:$IMAGE_TAG
```

Check PostgreSQL logs:

```bash
docker logs my_postgres
```

Wait until PostgreSQL is ready:

```bash
until docker exec my_postgres pg_isready -U admin -d mydatabase; do
  sleep 2
done
```

## 10. Run Backend Container

```bash
docker run -d \
  --name my-python-container \
  --network mynetwork \
  --restart unless-stopped \
  -e DB_HOST=my_postgres \
  -e DB_PORT=5432 \
  -e DB_NAME=mydatabase \
  -e DB_USERNAME=admin \
  -e DB_PASSWORD=12345 \
  -e DB_SSLMODE=disable \
  -e CORS_ORIGINS="*" \
  -p 5000:5000 \
  667173675235.dkr.ecr.ap-south-1.amazonaws.com/my-devops-webapp-backend:$IMAGE_TAG
```

Check backend logs:

```bash
docker logs my-python-container
```

Test backend API:

```bash
curl http://localhost:5000/ready

curl http://localhost:5000/students

curl http://localhost:5000/items
```

## 11. Run Frontend Container

Replace `YOUR_EC2_PUBLIC_IP` with your EC2 instance public IP address.

```bash
docker run -d \
  --name my-frontend-container \
  --network mynetwork \
  --restart unless-stopped \
  -e API_URL="http://YOUR_EC2_PUBLIC_IP:5000" \
  -p 3000:80 \
  667173675235.dkr.ecr.ap-south-1.amazonaws.com/my-devops-webapp-frontend:$IMAGE_TAG
```

Check frontend logs:

```bash
docker logs my-frontend-container
```

## 13. Access the Application

Open your browser and access:

```text
http://YOUR_EC2_PUBLIC_IP:3000
```

Backend API:

```text
http://YOUR_EC2_PUBLIC_IP:5000
```

**EC2 Security Group:**

Allow the following inbound ports:

| Port | Purpose |
|---|---|
| 22 | SSH |
| 3000 | Frontend |
| 5000 | Backend API |

Do not expose PostgreSQL port 5432 publicly.

### Remove Containers

```bash
docker rm -f my-frontend-container

docker rm -f my-python-container

docker rm -f my_postgres
```

### Remove Unused Images

```bash
docker image prune -a
```

**Warning:** Do not remove the `pgdata` volume if you want to preserve your database records.
